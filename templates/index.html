📖 Sobre SocraBot

Un proyecto educativo que implementa el método mayéutico de Sócrates para fomentar el pensamiento crítico a través del diálogo y las preguntas.

🛠️ Tecnologías utilizadas

  • Python + Flask — Backend y lógica del bot
  • HTML + CSS + JavaScript — Interfaz de usuario
  • Render — Hosting en la nube
  • GitHub — Control de versiones
